currently living in `README.md` is **archived to `docs/v0/README-v0.md` with a

## 2. Why this is not a judgement call

CORE states it outright: *"Supersedes `psyai-llc/PSYKI` (v0 sketch) and
`mypsyai/AgentAgent2` (quarry). Where any repo disagrees with this document,
this document wins and the repo gets reshaped."* CORE §9 goes further and lists
v0's module map among the things to leave behind, noting it *"never matched the
tree."*

The repo-wide canon rule (newest wins) points the same direction: `PSYKI_CORE.md`
was committed after the README revision.

So there is no architectural decision here. The decision is only about *disposal
method* — and the answer is archive, not delete, because v0 contains three
empirically-earned results that CORE §9 explicitly ports forward and that must
remain citable:

1. the Buridan deadlock in the BG gate and the lateral-inhibition fix
2. the sealed-context whitespace→word-boundary audit fix
3. the ablation rule (*a component whose ablation changes no metric was metaphor, and gets deleted*)

Item 3 is the most valuable thing v0 produced and it is **promoted into CORE**,
not archived with it. See §5.

## 5. The KI role contradiction — resolved

**The contradiction:** CORE §0 defines KI as *"certifying authority. Admits,
certifies, revokes."* v0 defines Ki as an action selector running a basal-ganglia
go/nogo gate. CORE §9 then says to *keep* the lateral-inhibition BG fix — which
only makes sense if a BG gate survives.

**Resolution: both are true, because they are the same operation.**

KI is a certifying authority. The act of certification *is* a selection: given a
plan of objectives and a frozen State snapshot, KI decides which task is admitted
to execution now. That decision is exactly what a basal-ganglia gate computes —
`go` (readiness × priority × staleness) against `nogo` (cost × risk × in-flight),
with a conflict term that can force a global stop.

So: **the BG gate is KI's admission mechanism, not a separate stage.** Emitting a
certificate is "go." Refusing admission is "nogo." Revocation on a stale
`state_rev` is the freshness check in CORE §6a. Nothing is deleted for being v0;
`neuro.py` is *demoted* from a top-level component to an internal implementation
detail of `ki.py`.

**Consequence — and this is the load-bearing part:** every component in
`neuro.py` (`ALIFGate`, `BasalGangliaGate`, `Neuromod`, `SDRRouter`,
`HomeostaticBudget`, `EligibilityCredit`, `DeltaContext`) now has to justify
itself *against CORE's invariants*, not v0's. Two are immediately suspect:

- **`Neuromod`** (DA/ACh/NE/5-HT → temperature, model tier, horizon) selects
  *model temperature*. Under CORE, model binding is TaskMaster's job (§8) and
  KI never calls a model (I3). Neuromod either moves to TaskMaster or dies.
- **`DeltaContext`** was v0's token-economy trick for PSY. CORE's I10 ("dynamic
  context choke ≤ server capacity") covers the same ground with a different
  mechanism. One of the two is redundant. **FLAG-4.**

The v0 ablation rule is hereby **promoted into canon** and applies to this
sorting: any component that survives into `psyki/ki.py` must ship an ablation
flag, and if ablating it changes no metric in the R3 test matrix, it is deleted.

## 6. Flaw enumeration

- **Archiving v0 preserves a contradiction in the repo.** A future model reading `docs/v0/` without the banner will re-derive the wrong architecture. Mitigated by the banner and by the terminology table above, but not eliminated. The honest fix is that `docs/v0/` must never be added to any agent's retrieval corpus. R1's `AGENTS.md` must exclude it explicitly.
- **CORE is itself unverified.** It asserts 12 invariants and specifies zero tests. R0.2 addresses this by making the gap explicit rather than by closing it — closing it is R1–R3 work. Until then, calling CORE "canon" grants authority to a document whose claims are entirely untested.
- **CORE was authored partly blind.** Its §9 port manifest was written against `mypsyai/AgentAgent2`, which the v0 README says was unreachable at authoring time. The port list may name files that do not exist. This is checkable the moment the zip is extracted — **FLAG-3**.
- **This decision reduces v0's measured results to prose.** The 98.1% wake-reduction figure, the deadlock table, the determinism-over-200-worlds run — none of those measurements survive as executing tests unless R3 re-establishes them. A measurement recorded in a README that no longer runs is a claim, not a result.
