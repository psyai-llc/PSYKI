## 7. Corpus filename hygiene

`corpus/` filenames currently contain spaces, colons, trailing spaces before
extensions, missing extensions, and one doubled name. These break shell
pipelines, break on Windows checkouts (colon is illegal), and will break any
retrieval indexer.

Rename all `corpus/` files to lowercase kebab-case with correct extensions.
Specifically confirmed problems:

| Current | Target |
|---|---|
| `GeminiPromptCodex-ResearchSources.mdGeminiPromptCodex-ResearchSources.md` | `gemini-prompt-codex-research-sources.md` |
| `CoPilot: Objective Coding Rules and Context Integration .md` | `copilot-objective-coding-rules.md` |
| `The Phi Model guide` | `the-phi-model-guide.md` *(verify content is markdown first; if PDF bytes, use `.pdf`)* |
| `Objective Coding Rules and Context Integration for AI Agents.md` | `objective-coding-rules-for-ai-agents.md` |
| all others with spaces | kebab-case equivalent |

Note the near-duplicate pair `CoPilot: Objective Coding Rules...` and `Objective
Coding Rules and Context Integration for AI Agents.md`. Diff them. If one
subsumes the other, delete the subsumed file and record it. If genuinely
different, keep both with distinct names.

Write `corpus/INDEX.md`: one line per file — filename, source, date acquired,
one-sentence description. Corpus without an index is a pile.
